## Inference evidence

Pinned inputs:

- Laya source commit: `970dc8c5f63d7b886a68409493f37d569424f933`.
- Hugging Face multilingual revision: `55cf4c4ebb4ebe31b2550e8bdf3bd21b99753851`.
- `model.safetensors` SHA-256: `9d628fd971b700382ac6f65920a86f149777b2e748e0c955fb3b19695aa8f204`.
- ONNX opset: 18; PyTorch `2.7.1`; Transformers `4.53.3`; ONNX `1.18.0`; ONNX Runtime `1.22.1`; Tokenizers `0.21.4`.

The exporter initially failed under PyTorch 2.7 because the pinned script used `dynamic_shapes` without `dynamo=True`, and then because inference tensors were passed into the head capture. The development patch in [`tests/Inference.Tests/export-strict.patch`](../../tests/Inference.Tests/export-strict.patch) enables the dynamo exporter, removes conflicting dynamic axes, requires strict weight loading, and clones temporary reference inputs before export. The resulting `encoder.onnx` and `head.onnx` both pass `onnx.checker` and the exporter’s three torch-vs-ONNX checks. Maximum exporter-reported logit delta was `1.2e-6`; action-probability delta was `0`.

The reproducibility manifest is generated by [`package_probe.py`](../../tests/Inference.Tests/package_probe.py). It records all graph/external-data hashes, tool versions, opset, and graph I/O dtypes/ranks. The split head input is explicitly `BOOL` for `marker_mask`; the C# binding was checked against that signature.

## Native crash record

The earlier `native_tests.exe.17584.dmp` contains a `0x80000003` in `ucrtbased.dll` from an abort/terminate path. The executable and PDB that produced it were overwritten by a later rebuild, so no source line can be responsibly assigned. A fresh matching-symbol Debug build with the current sources passed 30 serial runs, so the current implementation is not reproducibly crashing on this host; this does **not** prove the historical failure's cause. Automatic file actions remain disabled until the production transaction and fault-injection gate.
