# DeskNext 0.4.0 Preview 2 · Windows x64

English · [简体中文](#简体中文)

> **Unsigned development preview.** Back up important files and start with a test folder. No unattended organization is enabled. This is not P4/P7 completion or a production release.

## Changes since Preview 1

- **Default classification templates fit better.** Opaque space GUIDs no longer consume the local model's limited option budget. Request-local short IDs map back to the same workspace spaces. Category descriptions and the two special choices are preserved; nothing is silently truncated. All 36 built-in template/language combinations passed the native-tokenizer check. This corrects input sizing, not proven classification accuracy.
- **Model storage can move without losing the old cache.** New downloads live under `.desknext-downloads` at the selected installation location. Complete verified previous downloads can be copied and reused offline; old files stay. Incomplete caches and retained model directories are not automatically deleted. Save settings after a successful install to activate it.
- **Worker compatibility is explicit.** Local requests and replies bind a protocol version and model-manifest digest. An incompatible host is refused rather than silently used. Native ONNX environment cleanup is explicit; the source-level macOS exit crash was reproduced and corrected with a native follow-up. This download still contains Windows x64 only.
- **Windows type icons initialize COM on the background thread** as required by the Shell API.

## Download, run and upgrade

Download `DeskNext-0.4.0-preview.2-win-x64.zip` and extract the entire archive. Run `payload/DeskNest.App.exe` for a portable launch. Keep all payload files together. You do not need Python or an installed .NET SDK; the optional [Laya model package](https://github.com/WSXYT/DeskNext/releases/tag/model-laya-multilingual-fp32-v1) remains separate and unchanged.

For a per-user install or upgrade, close DeskNext and follow the included `README.md`/`Install.ps1`. Do not overwrite an old version directory. Existing workspace GUIDs and model settings are not migrated by these changes. Uninstall preserves workspaces, models and unknown files. Follow your organization's execution policy; verify the checksum before deciding to run an unsigned build.

## Checked scope

The actual installed executable passed the three frozen A–D reference comparisons, versioned CPU model loading, verified-cache reuse, explicit activation and reopened preview, default-template budget checks, and model suggestion → confirmation → journaled import → undo. Uninstall retained an unknown-file sentinel. The earlier A/B/C references were reused unchanged—not regenerated to match this build.

Still open: independent human-labeled quality data, live Jev acceptance, permanent model/cache removal, signing, clean-machine/hardware validation and remaining automation/release work. No automatic file moves, GPU validation or large-sample accuracy is claimed.

## 简体中文

> **未签名开发预览版**，不是正式发行或 P4/P7 全部验收完成。请备份重要数据，先用测试文件体验；无人值守自动整理仍未启用。

### 这次修正了什么

- **默认中文分类模板的输入预算问题**：不再把冗长的空间 GUID 塞进模型选项。请求内的短 ID 仍映射到原来的空间，全部名称、说明和两个特殊选项保留，没有静默截断。十二语言、三种默认模板共 36 个组合通过原生分词检查；这不等于分类准确率验收。
- **下载缓存跟随安装位置**：优先复制可用的完整已校验旧缓存，在新位置离线复用。旧文件保留，安装成功后仍需保存设置才能启用；不自动删除未完成缓存或旧模型。
- **推理进程校验版本和模型身份**，不兼容时拒绝使用。源码中的 macOS 原生退出崩溃也已修正并定向复验；本次附件仍仅包含 Windows x64。
- **后台 Windows 文件类型图标补齐 COM 初始化**，不改动真实用户文件。

### 启动与升级

下载下方 `DeskNext-0.4.0-preview.2-win-x64.zip`，完整解压后运行 `payload/DeskNest.App.exe`。不要只复制主程序；运行时无需 Python 或 .NET SDK。独立的模型包没有变化，不必因为更新应用而重复下载模型。

按用户安装/升级请先关闭 DeskNext，再按包内 `README.md` 运行 `Install.ps1`，不要覆盖旧版本目录。这些改动不迁移既有空间 GUID 或模型设置；卸载也会保留工作区、模型和未知文件。请遵守所在组织的脚本策略，并核对校验和后决定是否运行未签名程序。

此安装版通过了固定 A–D 对照、新协议 CPU 加载、缓存复用、保存启用与重开预览、默认模板预算、“建议→确认导入→撤销”以及卸载保留文件检查。旧 A/B/C 参考没有重新生成。人工质量数据、真实 Jev、永久清理、签名及剩余发行验收仍未完成，不以测试样例冒充全面可用性。
