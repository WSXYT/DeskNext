# 栖格 · DeskNest

桌面文件的分类空间：在格子窗口中使用文件，智能分拣可选 Jev 或本地 Laya。

> 当前为工程初始化阶段，仅有规划与空项目骨架；尚无可用的桌面应用。进展与验收标准见 [PLAN.md](PLAN.md)。

初期以 Windows 10/11 为优先目标，同时规划 macOS 与 Linux。文件操作、模型推理和各平台安装包必须分别通过计划中的安全验收后才会启用。
